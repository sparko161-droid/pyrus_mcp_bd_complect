## Создание карточки клиента

Единственный подпроцесс, который запускает бот.

| Что | Значение |
| --- | --- |
| Форма | Карточка клиента, `2441100` |
| Когда запускается | При обращении от клиента, у которого карточки ещё нет |
| Кто запускает | Бот |
| Что с родительской задачей | Продолжается; ссылка на карточку записывается в поле `task_clients` |

Бот сначала **ищет** существующую карточку и создаёт новую только если не нашёл. Клиенту при этом пишется, что карточка создана.

### Что переносится в карточку клиента

| Данные | Колонка в Service Desk | Колонка в карточке клиента |
| --- | --- | --- |
| CRMID заведения | 39 | 6 |
| ИНН заведения | 40 | 13 |
| Ссылка на карточку заведения | 41 | 8 |
| Название заведения | 42 | 11 |

Номера колонок зашиты в код с обеих сторон. Перестановка колонок в любой из двух форм сломает перенос молча — данные уедут не в ту колонку.

## Связь с карточкой ресторана

| Что | Значение |
| --- | --- |
| Форма | Карточка ресторана, `1101763` |
| Как связывается | Поле `restoran` (id 33) — ссылка на задачу карточки |
| Как ищется | По CRMID (поле 92 карточки) либо по ИНН |

### Синхронизация полей заведения в обращение

Включена (`RESTAURANT_FIELDS_TO_SD`). Поля переносятся **по совпадению кодов**: если в карточке ресторана и в обращении есть поля с одинаковым кодом, значение копируется.

Следствие, о котором нужно помнить: **добавление в обе формы полей с одинаковым кодом автоматически включает их в синхронизацию.** Это не настраивается списком — совпадение кода и есть правило.

## Входящие связи

| Источник | Способ | Что передаёт |
| --- | --- | --- |
| Мессенджер клиента | Внешний канал Pyrus | Текст обращения, `SenderName`, телефон, `message_chanell_id` |

## Внешние интеграции

Собственных обращений к сторонним системам у бота нет: он работает только с API Pyrus.

Поле ИНН называется `Dadata_inn`, что указывает на интеграцию с DaData, но заполняет его **не этот бот** — он только читает значение. Чем именно заполняется, требует уточнения.

## Требует уточнения у заказчика

1. **Полный перечень полей с совпадающими кодами** в карточке ресторана и в обращении — то есть что фактически синхронизируется сегодня.
2. **Чем заполняется `Dadata_inn`**: интеграцией, другим ботом или вручную.
3. Есть ли обратная передача из обращения в карточку ресторана (например, история обращений).
4. Что происходит с карточкой клиента, если у одного клиента несколько заведений — заводится одна карточка или несколько.
