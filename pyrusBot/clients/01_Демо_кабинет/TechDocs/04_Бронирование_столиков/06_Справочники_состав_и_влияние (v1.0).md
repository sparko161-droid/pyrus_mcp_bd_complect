## Справочники формы 2445773

В форме используются 4 основных справочника. Их состав выгружен напрямую из Pyrus API.

### 1. Справочник 303729 («Тип заявки»)

Используется в поле `request_type` (ID 7).

| Item ID | Значение | Описание |
| --- | --- | --- |
| 179704574 | Мероприятие (Событие) | Заявка на организацию праздника (включает доп. шаги) |
| 179704577 | Обычный визит | Стандартное бронирование столика |

---

### 2. Справочник 303727 («Мероприятия»)

Используется в поле `event_name` (ID 8). Отображается при `request_type` = Мероприятие.

| Item ID | Значение | Описание |
| --- | --- | --- |
| 179704521 | День Рождения | Празднование дня рождения |
| 179704524 | Корпоратив | Корпоративный праздник компании |
| 180781574 | Девичник | Девичник перед свадьбой |
| 180781573 | Мальчишник | Мальчишник перед свадьбой |
| 179704526 | Выпускной | Выпускной вечер |
| 179704527 | Юбилей | Юбилейная дата |
| 180781406 | Другое | Требует уточнения в поле `event_name_other` |

---

### 3. Справочник 303731 («Желаемый зал/зона»)

Используется в поле `hall_zone` (ID 16).

| Item ID | Значение | Описание |
| --- | --- | --- |
| 179704662 | Основной зал | Главный зал заведения |
| 179704675 | Банкетный зал | Изолированный зал для мероприятий |
| 179704697 | Летняя веранда | Открытая веранда в тёплый сезон |
| 179704700 | Барная зона | Столы у барной стойки |

---

### 4. Справочник 303732 («Статус заявки»)

Используется в поле `12` (Раздел «Статус обработки»).

| Item ID | Значение | Кто выставляет |
| --- | --- | --- |
| 179704752 | Новая | Выставляется ботом при создании / передаче оператору |
| 179704754 | Ожидает подтверждения | Выставляется менеджером при согласовании брони |
| 179704753 | Подтверждена | Бронь успешно подтверждена |
| 179704797 | Отклонена | Отмена брони |
| 179704817 | Завершена | Визит прошёл |
