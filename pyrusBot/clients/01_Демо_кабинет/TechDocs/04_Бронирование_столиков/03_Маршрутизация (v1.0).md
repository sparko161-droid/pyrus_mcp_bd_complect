## Маршрут задачи бронирования

Маршрутизация задачи строится на смене ответственного лица и статусов задачи по мере прохождения этапов.

```mermaid
stateDiagram-v2
    [*] --> СборИнформацияБотом: Задача создана из мессенджера
    СборИнформацияБотом --> ПереданоОператору: Все поля собраны / Запрос оператора / 3 ошибки
    ПереданоОператору --> Подтверждено: Менеджер согласовал стол
    ПереданоОператору --> Отклонено: Нет мест / Гость отменил
    Подтверждено --> Завершено: Визит состоялся
    Отклонено --> [*]
    Завершено --> [*]
```
