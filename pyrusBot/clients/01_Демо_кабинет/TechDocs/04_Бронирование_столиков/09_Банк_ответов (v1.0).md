## Сообщения бота квалификации (`booking_bot`)

| Ключ | Текст сообщения | Ситуация отправки |
| --- | --- | --- |
| `WELCOME` | Здравствуйте! Подскажите, пожалуйста, как к Вам можно обращаться? | Первый ответ бота при создании задачи |
| `PHONE_HINT` | Укажите, пожалуйста, Ваш номер телефона для связи. Подойдёт номер в формате 79XXXXXXXXX или 89XXXXXXXXX. | Запрос телефона |
| `EMAIL_HINT` | Укажите, пожалуйста, Вашу электронную почту (или напишите «нет», чтобы пропустить). | Запрос email |
| `GUESTS_HINT` | На какое количество персон планируется бронирование? | Запрос кол-ва гостей |
| `DATE_HINT` | Укажите желаемую дату и время визита (например: 25.10.2026 19:00 или 19:00). | Запрос даты/времени |
| `OPERATOR_CALL` | Уже зову коллегу — оператор подключится к диалогу в ближайшее время. | При фразах «оператор», «человек» |
| `MAX_ERRORS` | Не получается разобрать ответ. Передаю диалог оператору, он свяжется с Вами. | При 3 ошибках ввода подряд |
| `DONE` | Спасибо! Все данные по бронированию собраны. Передаю заявку администратору, с Вами свяжутся для подтверждения. | При успешном завершении всех шагов |
