## Автоматические проверки

Логика бота прогоняется локально до деплоя — `npm run test`. Сеть подменена: ответы Pyrus объявляются маршрутами, а незаявленный вызов попадает в `network.unmatched` и проверяется на пустоту. Тест, ушедший в боевой `api.pyrus.com`, считается сломанным.

Сейчас автоматически проверяется:

| Что | Ожидаемый результат |
| --- | --- |
| Первый ответ боту | Бот спрашивает, как обращаться |
| Запись состояния | Состояние записано в поле `technical_bot_state` (id 26), вложенное в заголовок |
| Чтение схемы формы | Схема прочитана из API один раз за запуск |
| Обращения наружу | Все объявлены тестом; незаявленных нет |

## Сценарии приёмки

| № | Сценарий | Шаги | Ожидаемый результат | Статус |
| --- | --- | --- | --- | --- |
| 1 | Полный заказ с доставкой | Пройти опрос до конца, выбрав доставку | Все поля доставки заполнены, поля самовывоза не спрашивались, заявка передана менеджеру | не проверено |
| 2 | Полный заказ с самовывозом | То же, выбрав самовывоз | Спрошены точка и время самовывоза; адрес доставки не спрашивался | не проверено |
| 3 | Детский день рождения | Выбрать тип мероприятия «Детский день рождения» | Бот дополнительно спрашивает пол ребёнка | не проверено |
| 4 | Аллергия | Ответить, что аллергия есть | Бот спрашивает уточнение по аллергии | не проверено |
| 5 | Гость зовёт человека | Написать «позовите оператора» | Бот прекращает опрос и передаёт диалог | не проверено |

## Краевые случаи

| Случай | Ожидаемое поведение |
| --- | --- |
| Гость отвечает «не надо» на вопрос с галочкой | Записывается «не отмечено». Отрицание не должно распознаваться как согласие из-за подстроки «надо» |
| Гость отвечает номером пункта («3») | Выбирается третий вариант из показанного списка |
| Гость пишет начинку с опечаткой | Подбор по началу слов; при неоднозначности бот переспрашивает, а не угадывает |
| Гость называет вес «1,5 кг» | Записывается 1.5. Значение вне границ 0.5–50 отклоняется, бот переспрашивает |
| Телефон в любом формате | Приводится к `79XXXXXXXXX`; иначе бот переспрашивает |
| Время самовывоза «в 14» | Записывается 10:00 UTC при смещении +4 |
| Один и тот же вебхук пришёл дважды | Второй игнорируется по `last_event_key`, повторного вопроса нет |
| Бот прокомментировал сам себя | Игнорирует, цикла не возникает |
| Один вопрос задан 4 раза | Диалог передаётся оператору |
| Три нераспознанных ответа подряд | Диалог передаётся оператору |
| Справочник недоступен | Вариантов нет, бот не падает; поведение при этом требует уточнения |
| Поле скрыто условием видимости | Вопрос по нему не задаётся |

## Требует уточнения у заказчика

- Приёмочные сценарии никем не подписаны: нужны дата, участники и результат.
- Поведение при недоступном справочнике: переспрашивать гостя, принять свободный текст или сразу звать оператора.
- Что считать успешной приёмкой: доля заявок, доведённых ботом до конца без оператора.
