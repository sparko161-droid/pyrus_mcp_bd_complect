Справочник — это список значений, из которых выбирают при заполнении формы: например, список начинок, точек самовывоза или типов мероприятия. Если нужного значения в списке нет, его нельзя «дописать руками» в задаче — сначала значение добавляют в справочник, и только потом оно появится в форме.

## Справочник: TODO название

**Зачем нужен:** TODO — своими словами, без технических кодов.

**Открыть справочник:** TODO прямая ссылка в Pyrus.

**Кто отвечает за пополнение:** TODO. За доступом на редактирование обращайтесь к TODO.

### Как добавить новое значение

1. Откройте справочник по ссылке выше.
2. Нажмите «Добавить строку».
3. Заполните колонки:

| Колонка | Обязательная | Формат | Пример |
| --- | --- | --- | --- |
| TODO | да | TODO | TODO |
| TODO | нет | TODO | TODO |

4. Сохраните.

**Когда значение появится в форме:** TODO (обычно сразу; в уже открытых вкладках — после обновления страницы).

### Как изменить значение

Изменение названия строки меняет её **везде**, включая уже созданные задачи. Если нужно именно новое значение, а не исправление опечатки, добавьте новую строку, а старую выведите из обращения.

### Как убрать значение из списка

Не удаляйте строку. Удаление разрывает связь с уже созданными задачами: в старых заявках значение перестанет отображаться корректно, а отчёты по ним «потеряют» эти заявки.

Правильно: TODO — описать принятый в этом справочнике способ (колонка «Активно» = нет, перенос в архивную папку и т. п.).

### Частые ошибки

| Что сделали | Что произошло | Как правильно |
| --- | --- | --- |
| Переименовали строку, чтобы «переиспользовать» её под другое значение | Во всех старых задачах значение подменилось задним числом | Добавить новую строку, старую вывести из обращения |
| Удалили строку | Старые задачи потеряли значение, отчёты разошлись | Вывести из обращения |
| Добавили значение с лишним пробелом в начале | Автоподстановка не находит строку, бот переспрашивает клиента | Проверить значение на лишние пробелы |
| Добавили дубль уже существующего значения | Бот не может выбрать между двумя строками и не заполняет поле | Проверять список перед добавлением |
