## Справочники формы 2453887

### 1. Справочник № 305780 («Меню»)
- **Назначение:** Позиции готовой продукции каталога для выбора при предзаказе (Вопрос 8).
- **Поле формы:** `order_items` (id: 5 в табличной части `4`).
- **Колонки:** `Меню` (text), `Категория` (text).
- **Особенности:** Администратор кондитерской добавляет/удаляет позиций в справочнике Pyrus. Бот подхватывает изменения автоматически при обращении к API (`pyrus.catalogs.get({ id: 305780 })`).

### 2. Справочник № 306384 («Начинка торта»)
- **Назначение:** Доступные начинки для заказных тортов (Вопрос 5).
- **Поле формы:** `cake_filling` (id: 19 в группе `15`).
- **Колонки:** `Начинка торта` (text).
- **Содержимое:** Сникерс, Орех, Чёрный лес, Молочная девочка, Чистый мёд, Черничный, Красный бархат.
