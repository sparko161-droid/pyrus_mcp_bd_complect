## Пошаговый сценарий диалога бота

```mermaid
stateDiagram-v2
    [*] --> Q1_Name: Создание задачи / Первый комментарий
    Q1_Name --> Q2_Phone: Имя указано
    Q2_Phone --> Q3_ProductType: Телефон валиден (7XXXXXXXXXX)
    
    state Q3_ProductType {
        [*] --> CheckLock
        CheckLock --> CustomAllowed: Нет активной задачи блокировки в 2456232
        CheckLock --> CustomBlocked: Есть непросроченная задача в 2456232
    }
    
    Q3_ProductType --> Q4_CakeType: Выбран пункт 1 (Торт на заказ) & CustomAllowed
    Q3_ProductType --> Q3_ProductType: Выбран пункт 1 & CustomBlocked (Бот отсылает уведомление)
    Q3_ProductType --> Q8_CatalogItems: Выбран пункт 2 (Готовые позиции)
    
    Q4_CakeType --> Q5_Filling: Выбран тип торта (Бенто / От 2кг)
    Q5_Filling --> Q6_Weight: Торт от 2кг (вариант 2)
    Q5_Filling --> Q7_Design: Бенто торт (вариант 1)
    
    Q6_Weight --> Q7_Design: Вес >= 2 кг
    Q6_Weight --> Q6_Weight: Вес < 2 кг (Повторный запрос)
    
    Q7_Design --> Q10_PickupDate: Фото/описание приложено
    
    Q8_CatalogItems --> Q9_Quantity: Выбрана позиция из справочника 305780
    Q9_Quantity --> Q10_PickupDate: Указано количество
    
    Q10_PickupDate --> Q11_PickupTime: Дата >= 4 рабочих дней
    Q10_PickupDate --> Q10_PickupDate: Дата < 4 рабочих дней (Повторный запрос)
    
    Q11_PickupTime --> Q12_DeliveryType: Время указано (ЧЧ:ММ)
    
    Q12_DeliveryType --> Q13_PickupPoint: Выбран 1 (Самовывоз)
    Q12_DeliveryType --> FinishDelivery: Выбран 2 (Доставка) (Сообщение со ссылкой на сайт)
    
    Q13_PickupPoint --> FinishPickup: Точка выбрана из справочника 305781
    
    FinishDelivery --> [*]
    FinishPickup --> [*]
```

## Правила перехода и валидация

1. **Имя гостя:** Произвольный текст.
2. **Телефон:** Строгая валидация формата (11 цифр, начинающихся с 7).
3. **Блокировка заказов:** Запрос задач в форме `2456232` без закрытых. Если есть задача с `period` $\ge$ текущего времени, отбивка блокировки.
4. **Вес торта:** От 2 кг. Округление/парсинг чисел.
5. **Рабочие дни:** Формирование минимальной доступной даты с учётом +4 рабочих дней (СБ и ВС не считаются).
6. **Доставка:** Отправка клиенту прямой ссылки `https://белыйфартук.рф/?ysclid=mspy6odhv7512300021` без обязательного запроса точки самовывоза.
