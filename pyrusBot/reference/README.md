# Справочные материалы

Здесь лежит то, что **не является документацией проекта**: чужие образцы и старые наработки, которые полезно иметь под рукой, но которые не описывают ни одного нашего процесса. Поэтому папка не синхронизируется с Базой знаний и не проверяется линтером документации.

## `pyrus_vendor/` — образцы от Pyrus

Шаблонные боты, справочные выгрузки и материалы вебинаров. Источник, из которого извлекаются приёмы, а не код, который мы поддерживаем.

- `Серверные_скрипты/` — шаблонный бот, бот копирования, маршрутизатор, мониторинг ответственных.
- `Формные_скрипты/`, `Советы_по_настройке/`, `Внутренний_вебинар/` — методические материалы.
- `Полезные функции.html`, `Скрипты.xlsx` — выгрузки, сделанные до заведения репозитория.

Правки сюда не вносятся: это чужой материал. Всё, что признано годным, переносится в Банк функций (`src/lib/`) — с типами, тестами и разбором дефектов оригинала.

## `legacy_config/` — конфигурация, вышедшая из употребления

`kb_sync_config.json` — задумывался как карта соответствия локальных папок и разделов Базы знаний, с числовыми ID баз и категорий. Ни один скрипт на него не ссылается: идентичность статьи в итоге стала жить в YAML-заголовке самого документа (`pyrus_id`), а корни разделов — в `.env`. Файл сохранён как след принятого и отменённого решения, чтобы его не завели заново.

## `legacy_bots/` — боты, ещё не разложенные по клиентам

Работающий (или работавший) код реальных внедрений, попавший в репозиторий до появления структуры `clients/`. Каждый должен переехать в кабинет своего клиента — `clients/NN_Клиент/Forms/NN_Форма/scripts/` — вместе с восстановленной документацией. Этим занимается роль `pyrus_reverse_documentarian`.

| Файл | Что делает | Статус |
| --- | --- | --- |
| `locanta_bot_pyrus_temp.ts` | Диалоговый бот Service Desk: принимает обращение ресторана из мессенджера, опознаёт заведение, заводит карточку клиента, собирает тип заявки и приоритет, зовёт оператора | **Документируется** |
| `restoran_bot.ts` | Синхронизация доступов (iiko, RMS, агрегаторы доставки) между карточкой заведения и задачами | Ждёт очереди |
| `OLD_dialog_bot.ts` | Ранняя версия линии `locanta`: те же коды полей и те же формы | **Устарел.** Не документируется, за основу не берётся |
| `extract_scripts.py` | Разовый импорт `Скрипты.xlsx` → `scripts_dump.json` | Не бот, документации не требует |

До переезда файлы исключены из проверки типов: они писались вне текущих соглашений и не должны блокировать сборку.
