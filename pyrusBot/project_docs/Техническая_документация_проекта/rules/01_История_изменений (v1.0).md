- v1.0 (10.08.2026): Введено обязательное правило: увидел `form_id` и ещё не документировал форму — выгрузи её состав из API, и только потом составляй спецификацию. У заказчика спрашивается лишь то, чего в API нет: смысл поля, владелец справочника, состав ролей, часовой пояс. Правило внесено в процесс документирования, в роли документатора, аналитика и ревьюера и в навык серверных ботов.
