# Pyrus MCP Server Release v1.0.0

**Release Tag:** `v1.0.0`
**Release Date:** 2026-08-18
**Status:** General Availability (GA)

## 1. Summary of Capabilities
This milestone delivers the initial Enterprise-grade FastMCP server connecting AI Agent platforms (Claude Desktop, Cursor, Custom SDKs) to the Pyrus v4 API.

### Key Highlights
- **1:1 Parity with Legacy Toolkit:** Full read and write support for Tasks, Forms, Catalogs, Members, Roles, Announcements, and File Attachments.
- **Enterprise Multi-Tenancy & Auth:** Dynamic v4 Auth proxy, cryptographic bearer tokens, tenant context isolation via `contextvars`, and granular scope middleware.
- **Resilient Upstream Communication:** Asynchronous connection pooling with `tenacity` exponential backoff (rate limit 5000 req/10m guard), and a strict 50MB response size ceiling.
- **Production Persistence:** SQLite via `aiosqlite` with WAL mode and idempotent startup migrations, plus optional Redis caching adapter.
- **Enterprise Observability:** Centralized JSON logging with secret redaction, Prometheus metrics export (`/metrics`), 4 SLO alerting rules, and 3 operational runbooks.
- **Real-Time Ingestion:** Secure `/webhook` endpoint featuring SHA1-HMAC signature verification (`X-Pyrus-Sig`) and idempotent event storage.

## 3. Configuration Contract
| Parameter | Description | Required | Default |
|:---|:---|:---|:---|
| `PYRUS_LOGIN` | Pyrus Bot account email | Yes | - |
| `PYRUS_SECURITY_KEY` | Pyrus Bot security key | Yes | - |
| `PYRUS_WEBHOOK_SECRET` | Secret for HMAC signature validation | Yes | - |
| `PYRUS_API_URL` | Base URL for Pyrus v4 API | No | `https://api.pyrus.com/v4` |
| `REDIS_URL` | Optional Redis connection string | No | `""` (In-memory) |
| `PORT` | Server listening port | No | `8000` |
| `HOST` | Server bind host | No | `0.0.0.0` |
| `MCP_TRANSPORT` | MCP Transport mode (`sse` or `stdio`) | No | `sse` |
| `ENABLE_TENANT_ISOLATION`| Enforce strict token validation | No | `true` |
